# 公開サイト

読者が認証なしで開く画面の約束 — アドレス、言語、何を公開と言うか、検索式と絞り込みの意味、書き出し、
カート。画面の姿は `app/routes/` と部品が持ち、ここには書かない。機械が読む JSON は
[public-api.md](public-api.md) で、同じ公開集合の別の出口になる。

## アドレス

骨格は旧ポータルと同じにしてある。外部が焼き込んでいるのは HTML ページとファイルのアドレスで、形を
変えても得るものが無い。

| アドレス | 中身 |
|---|---|
| `/research` `/dataset` | 一覧 = 公開検索 (`?q=` `?sort=` `?order=` `?size=` `?page=`) |
| `/research/{研究 ID}` `/research/{研究 ID}/v{n}` | 最新の公開版と版の指定。どちらも 200 を返す |
| `/research/{研究 ID}/versions` | リリース情報 (公開版の一覧) |
| `/dataset/{データセット ID}` | データセット |
| `/research/export` `/dataset/export` | 一覧の結果の書き出し (`?format=tsv` / `?format=copy`) |
| `/cart` | 利用申請に持っていくデータセットの控え |
| `/news` `/news/{id}` `/{slug}` | お知らせと記事 ([site-content.md](site-content.md)) |
| `/{研究 ID}` と旧ポータルの形 (`-v{n}` `-latest` `-release` 付き) | 上のどれかへの redirect |
| `/en/…` | 上のすべての英語版 |

**到達性を約束するのは、研究のページ (最新と版の指定)、裸の研究 ID、記事の slug。** DDBJ Search が
`/{研究 ID}` でリンクを組み、外部の submission metadata がガイドラインの slug を焼き込んでいる。
**ファイルのアドレスは約束しない** — 形は保つが、公開状態は admin が切り替える。

- **記事は catch-all が受け、研究 ID と旧アドレスの解決を先に済ませる** (`app/routes/document.tsx`)。
  route が持つアドレス (`app/public/urls.ts` の `SCREEN_PATHS`) と同じ slug の記事は作れない
- **redirect は server で返す。** JS を実行しないクライアントにも届く
- **secondary の label で来たら primary のアドレスへ redirect する。** 旧いデータセット ID と訂正された
  研究 ID は、記事の地の文や申請書に書かれていて書き換えられない。大小文字だけが違う綴りも、綴りどおりの
  label が無く 1 つに決まるなら、pin の綴りのアドレスへ redirect する
- **版は `v` + 先頭に 0 を持たない番号の 1 つの綴りだけ。** `v01` は別のアドレスにせず 404 にする
- **公開されていないものと存在しない label は同じ 404。** 区別できると未公開の研究があることが漏れる

## 言語

**日本語は prefix を持たず、英語は `/en` の下。** 日本語に prefix を付けると、既に書き留められた
アドレスすべての前に redirect が挟まる。`/ja/…` は redirect で、1 つのページのアドレスは 1 つ。
**言語はアドレスだけから決め、cookie も `Accept-Language` も見ない** — 誰が開いても同じページが出る。
言語の切り替えは、いま見ているページの別言語へ、クエリを連れて行く。

**研究系の未翻訳のフォールバックは、ページの上部で 1 度だけ告げる。** 欄ごとに印を付けると、英語が
丸ごと無いページが印だらけになる。記事とお知らせは倒れずに 404 になる。

**アドレスのクエリは 1 つの綴りに揃える** (`normalizeQuery`)。`,` `:` `(` `)` はクエリの中で符号化しなくて
よい文字なので、同じアドレスがブラウザと server に別の綴りで届き、揃えないと hydration が食い違う。

**管理画面は日本語だけで、言語の prefix を持たない。** `/en/admin/…` は存在しない。扱う値は 2 言語のまま。

## 何を公開と言うか

**研究系は検索用の行 (`search_doc`) からしか集合を引かない** ([data-model.md](data-model.md))。
一覧・研究・版・データセット・カートの行・書き出し・JSON API のどれも同じ。取り下げられた版と削除された
データセットは、行が消えた時点でどこからも出なくなる。

- **版のページが名指すデータセットの一覧は版のもの、各データセットの記述は最新。** 過去の版のページは
  そう断る。削除されたデータセットは載らない
- **リリース情報の「追加されたデータセット」は、隣り合う公開版どうしの差。** 取り下げた版は比較から
  外れる (読者が開けない版との差を見せない)
- **関連論文が他の研究のデータセットを名指すときは、公開されているものだけがリンクになる。** 台帳が
  答えない ID は書かれたとおりの文字で出す
- **ダウンロードは公開 bucket の箱の list。** store が答えなければ節ごと出さず、ページの他の部分は
  外部の可用性に左右されない

**研究系の文は木をそのまま描き、HTML 文字列を作らない。** リンクの行き先は描く時点で検査し、
`http` / `https` / `mailto` / この origin に留まるサイト内の絶対パス / ページ内の `#…` 以外は文字だけに
する — 研究の文は保存時に行き先を見ないので、ここが唯一の検査になる。**検査するのは文字列の頭ではなく、
ブラウザと同じ規則で解決した行き先。** ブラウザはタブと改行を落とし `\` を `/` と読むので、`/\host` は
別のホストを指す。制御文字か `\` を含む行き先はリンクにしない (`app/content/richtext.ts`)。

## 検索式

**一覧は公開検索そのもの。** 研究の一覧は研究の行を、データセットの一覧はデータセットの行を引き、
版の行は引かない (同じ研究が版の数だけ並ぶ)。

**窓に打つのはキーワードで、検索式ではない。**

| 打ち方 | 意味 |
|---|---|
| 空白で区切る | すべてを含むもの |
| カンマで区切る | どれかを含むもの |
| `"..."` で囲む | その並びのまま |

窓の送信は `k` で届き、**そこから作った木を書き出した `?q=` のアドレスへ redirect する** — 1 つの検索が
1 つのアドレスを持ち、共有でき、JS 無しでも動く。記号を含む語 (`NGS(Exome)`) はクオートされて 1 語に
なる。

**`?q=` は検索式** (`app/search/dsl.ts`)。JSON API も同じ受け口を通る。

- **facet の条件は `キーの code:語彙値の code`** (`platform:hiseq-2500`)。id でもラベルでもなく code を
  載せるのは、rename がラベルの変更でしかないことをアドレスでも成り立たせるため
- **範囲は `key:[下限 TO 上限]`**、片側だけなら `*` (`read-length:[100 TO *]`、
  `date_published:[2020-01-01 TO *]`)。両端が空なら条件ごと消える
- **ICD10 のコードは、パネルが並べる 3 桁まで丸めて照合する。** 点の有無と大小文字は問わない。
  他の語彙値の code も大小文字を問わない
- **値は DB が受けられる形だけを読む。** 日付は実在する `YYYY-MM-DD` で年は 0001–9999、数は先頭に 0 を
  持たない 10 進だけ (`0x10` `1e3` は読まない)。それ以外は読めない `?q=` になる
- 読めない `?q=` は、結果を出さずに読めなかったことを告げる

**効いている条件は、窓に打った語も含めて 1 つの列に並び、1 つずつ外せる。** 列は `?q=` の木を読み
戻したものなので、そこに出ていない条件が効いていることが構造上ありえない。「すべて解除」は窓も空にする。

## 絞り込み

**絞り込んだ状態はアドレスに載る。** 値を選ぶことと外すことは同じリンクで、絞り込みの側は状態を持たない。
範囲は GET の form で、アドレスへの redirect で答える。どちらも並び・向き・件数 (`?sort=` `?order=`
`?size=`) を持ち回る。

- **件数は、その facet 自身の条件だけ外した集合で数える。** 全条件で数えると、1 つ選んだ瞬間に同じ
  facet の他の値が 0 件になって複数選べない
- **0 件の値は出さないが、選んだ値は 0 件でも残す。** 外す手段を消さない。値が 1 つも残らなくても
  facet の箱は残る
- **facet の並びはカテゴリと catalog の順、値は件数の降順。** 範囲の facet は件数を持たない
- **研究一覧での絞り込みは「配下のどれかのデータセットが持つ」。** 2 つの facet を別々のデータセットが
  満たしていても当たる
- **ICD10 は 3 桁だけを並べ、4 桁は根に丸めて数える。** 兄弟のコードを持つ疾患は根で 1 度だけ数える
- **日付の facet の相対の窓 (直近 1 / 5 / 10 年) は、絶対の下限日としてアドレスに載り、上限を置かない。**
  相対のまま載せるとアドレスの意味が一晩で変わる
- **値の一覧を絞る窓と、facet の開閉と、pane を畳んだかどうかはアドレスに載せない** — 結果の中身を
  変えないため。**範囲の入力だけは script を要る**。ほかは script 無しでも届く

## 並びと件数

- **並びは更新日・公開日・ID で、既定はどちらの一覧でも更新日の新しい順。** 既定と違う向きだけが
  `?order=` に載り、キーを選び直すと向きはそのキーの既定に戻る。**同点は日付と id で固定する** —
  揺れるとページをめくったときに同じ行が 2 度出る
- **関連度は並びに持たない。** スコアは全文の語を含む問いにしか定義されず、絞り込んだだけで並びの
  選択肢が変わる
- **日付を持たない行は向きによらず末尾**
- **1 ページは 20 / 50 / 100 件** (`?size=`、既定の 20 は書かない)。読めない `?page=` は 1 ページ目。選ぶと 1 ページ目に戻り、窓・並び
  替え・ページ送り・facet・言語の切り替えはどれもこの値を持ち回る。JSON API は 20 件固定
- **ページ送りの番号は、いまのページから離れるほど倍々に間隔が開き、最初と最後は常に出る** — どの
  ページからどのページへも数回で届き、リンクの数はページ数の対数でしか増えない (`app/components/page.tsx`)
- **0 件でも一覧は一覧のまま。** 表と絞り込みは残り、緩和した検索も打ち方の案内も出さない

## 書き出し

一覧は画面に出ている検索そのものを `/{一覧}/export` で渡す (ファイルとクリップボード)。

- **渡すのは全件で、見ているページではない。** 列は画面より多い
- **タブ区切りでクオートしない。** カンマは 1 つのセルの複数の値を繋ぐのに使う。値の中のタブと改行は
  空白に潰す
- **ファイルは BOM から始め、コピーには付けない。** 付けないと表計算が UTF-8 と読まない
- **`=` `+` `-` `@` で始まる値には `'` を前置する。** 表計算で開かれることを前提に書き出すので、数式として
  評価されないところまでが書き出しの責任。機械可読な経路は JSON API

## カート

制限公開データの利用申請は JGA の申請システムで行う。ポータルがするのは**申請書に貼る accession を
集めること**で、`/cart` の出口は JSON ひとかたまり。

- **中身はブラウザの `localStorage` だけが持つ。** server に行も、アカウントとの結び付きも無い。窓を
  閉じても残るので、空にするのはひと押し (共有端末で前の人の控えが残る)
- **入るのは JGAD のデータセットだけ。** 非制限公開に申請は要らず、ポータルが振った ID は申請システムが
  知らない。件数の上限は持たない
- **アドレスに載せない。** 行は `/cart/rows` に accession を送って server が検索用の行から組む。取り下げ
  られたものは行にならず、尋ねた accession は答えと一緒に返る
- **研究の行の印は 3 状態** (入っている / いない / 一部だけ)。押すとまだ入っていないものを入れ、全部
  入っていれば出す。押した結果の知らせは「取り消し」で押す前のカートに戻せる

## 意図的にやっていないこと

| やらないこと | 理由 |
|---|---|
| 窓から `field:value` を打つ経路 | 窓はキーワードの窓。field を持つ条件はアドレスと facet から入る |
| ICD10 のコードの入力欄・疾患名の autocomplete | 呼称は表記ゆれを含むので候補が汚れる。n-gram の全文検索と facet で足りる |
| label を打ったときの完全一致の別枠 | 全文検索の結果として並べる。裸の研究 ID はアドレスが redirect で受ける |
| 0 件のときの緩和した検索・打ち方の案内 | 外し方の数だけ検索することになり、宣伝しないと決めた構文を見せることになる |
| facet の「不明」 | 未確定と該当なしは集計にも検索にも載せない |
| cookie / `Accept-Language` による言語の選択 | 言語はアドレスが決める |
| 欄ごとの未翻訳の印 | ページ単位で 1 度だけ告げる |
| エクスポートの Excel 形式 | 表計算はタブ区切りを読む |
| robots.txt でのクロールの遮断 | 公開画面は読まれるために出している。未公開のものはトークンが要り、応答が `noindex` を持つ |
| 遷移中の骨組み (skeleton) | server の応答は 1 秒に満たず、出すと点滅する |
