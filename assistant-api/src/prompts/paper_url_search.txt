# 出力要件
- `source_url` には、論文概要を含むページを表示する URL を設定してください。
- PubMed、DOI のページ、出版社の論文ページを優先してください。
- Supplementary material、引用ページ、または書誌情報と部分的にしか一致しない別論文は選ばないでください。
- 正確な論文ページを特定できない場合、`source_url` は null としてください。
